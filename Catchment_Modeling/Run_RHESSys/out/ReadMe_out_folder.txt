The 'out' folder is where RHESSys outputs will be written to

Given large size of RHESSys output files, I have provided a processed subset of data that is used in fDOM prediction workflow (TR_for_predictions)


This folder also contains the output for the 1000 year spinup run and the subsequent 1850 - 2026 transient run.
Some files are too large to push to GitHub and are in turn zipped, if you want to look at this data you will need to unzip the following folders
out/ccrTR/HarvestNone/TR1850_2026_NOharvest_run_streamrouting.daily
out/ccrSPIN/spinup_run_basin.daily
out/ccrSPIN/spinup_run_grow_basin.daily
